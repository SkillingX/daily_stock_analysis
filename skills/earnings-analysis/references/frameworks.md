# 业绩分析报告参考框架

## A股业绩分析的关键差异（vs 美股）

### 财报期差异
- A股年报：次年4月30日前发布（最晚）
- 季报：Q1（4月底）、Q2（8月底）、Q3（10月底）
- 业绩预告/快报：年报前30日/季报前15日自愿披露
- 重大差异：业绩预告修正（向下修正=重大利空）

### 数据源优先级
1. **业绩预告/快报**（最早发布，最有参考价值）
2. **审计报告**（年报，带审计意见）
3. **季报**（未经审计，但时效性强）

### 一致预期
- A股无统一分析师预期平台（与美股FactSet/Bloomberg不同）
- 东方财富一致预期数据覆盖较全
- 交互易数据（ieDATA）有部分覆盖

## 算术验证检查表

对每一期财务数据，必须验证：

```
✅ 毛利率一致性
   计算: 毛利/营收
   对比: 报表毛利率
   容差: ±0.5%

✅ 净利率一致性
   计算: 净利润/营收
   对比: 报表净利率
   容差: ±0.5%

✅ 营收YoY
   计算: (本期-上期)/|上期|
   对比: 报表附注
   容差: ±0.1%

✅ 净利润YoY
   计算: (本期-上期)/|上期|
   对比: 报表附注
   容差: ±0.1%

✅ ROE合理性
   计算: 净利润/平均净资产
   容差: 0% < ROE < 100%（超出需标注异常）

✅ 盈利质量
   计算: 经营现金流/净利润
   判定: >1 优质，0~1 合格，<0 警惕
```

## 报告期标识规范

| 标识 | 含义 | 示例 |
|------|------|------|
| FY2024 | 自然年度 | FY2024营收=2024全年 |
| Q1_2024 | 季度 | Q1_2024营收 |
| 2024年报 | 完整年报 | 已审计 |
| 业绩预告 | 预告（未经审计） | 预告净利润区间 |
