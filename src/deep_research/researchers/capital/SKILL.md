# 资金面研究员

见模块 `src/deep_research/researchers/capital/`（分析框架/契约/解析）。

自 issue #56 起为单轮试点；issue #64 起资金面独立完成：单日/近5/近10交易日
主力净流入三窗口（同一实际截至日，`as_of_date` 贯穿展示与资格记录）与同报告
已装配的市值锚点（总市值/流通市值分开标识，整条复用既有字段级资格记录——
含来源/单位/币种/时点/财期/质量与拒绝原因，零新增出站）由代码经既有有界入口
准备后整体注入，模型执行一次无工具循环的结构化分析。机构/股东侧（机构持仓、
两期股东集中度、股权高管调查）已随 issue #64 退役：不再取数、不再注入任务、
不再产出机构评分或合成总分；行业资金榜同样退役：不是资金分析的输入、依据或
缺口前提——注入资料中不含行业排名属预期范围，按现有三窗口与市值资料完成
分析，不得把它当作缺失前提叙述。资金总分 = 合格 `flow_score`，由代码从模型
输出派生，合法零分保留，模型未形成可用评分时按真实降级处理。

金额单位不明不推断资金金额与方向；任一窗口缺失、单位未确认或资格拒绝时不
启动模型（仅市值合格不构成启动条件）。市值锚点资格沿用字段级口径
（rule_eligible 且带规范 unit，带 normalization_error 即否决，源级标注
不补造资格），拒绝记录整条保留；总市值入口与标量装配同键名序列
（total_mv/market_cap/total_market_cap），总/流通不混用。试点轮职责限定为
固定资料的分区解读（唯一 JSON 输出）：评级/目标价/时间维度、交易行动词表
与免责声明由既有规则与聚合层负责；合格金额由既有展示入口提供同源展示文本，
既有统计展示直接引用，等值单位展示保留原值含义与币种，未给的比较基期与
统计子集及其推导金额不当事实；时点按已给时点/财期作解读，未给更新核验
结果不声称全局最新，时效讨论写明所依据时钟，财期截止日不当作观测或披露时间；
资金窗口截至最近已收盘交易日（允许范围内的前一交易日须展示实际日期），
禁止把资金窗口写成报告当天。
