# Triage labels

五个规范角色使用下列目标标签；表格定义约定，不表示所有 fork 或上游已创建这些标签。

| 规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充必要信息 |
| ready-for-agent | ready-for-agent | 规格清晰，可交给 agent 实施；开工仍需满足阻塞关系 |
| ready-for-human | ready-for-human | 需要人工实施或处理 |
| wontfix | wontfix | 决定不处理 |

技能提到分流角色时使用本表对应标签；这些标签与 bug、documentation 等问题类型标签用途不同。初始化前检查目标仓库已有标签，在获得授权且具备权限时只创建缺少的标签，不覆盖已有同名标签，也不重命名或删除其他标签。缺少权限时报告缺项，不将失败当成已经初始化。
