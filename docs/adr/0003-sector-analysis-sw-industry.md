# 新版板块分析采用申万行业口径

东财公开接口访问失败时，旧版板块分析无法稳定取得主行业、行情和成分。iFinD 标准 HTTP API 实测覆盖 31 个申万一级行业指数的有效行情，以及样本行业的归属、成分和指数日线。新版板块报告以申万一级为默认主行业，展示二、三级归属，主报告的行情、趋势、同业和行业排名统一按一级口径。旧报告保留生成时的东财口径。

申万主行业无法确认，或该行业的合格行情与近期趋势均不可用时，允许最后尝试整份报告走原东财链路，并标明实际口径。目标交易日的合格行情或盘后采用的前一交易日合格收盘行情，均可保留申万口径。单个字段缺失或部分成分报价不可用时，保留已有申万数据并注明缺口。两条链路都失败时，保留可用事实并交付部分报告。

行业归属与指数成分分别确认。北交所股票有明确行业归属、但未纳入对应指数时，保留行业行情、趋势与可用个股行情，同业样本作为行业参考，目标股的成分内排名留空，报告标为部分。该成分范围差异本身不触发东财兜底。

盘中未取得合格当日行情时，允许展示最近一个已完成交易日的合格行情并标注日期和缺口，报告标为部分。休市日以最近已完成交易日为目标日期。目标日收盘行情或趋势日线未就绪时，可以采用前一交易日的合格收盘行情或连续趋势窗口，标明实际截止日。仅因采用前一交易日收盘数据，报告仍可评为完整。缺少已核实的近期催化时，报告仍标为部分，区分检索失败与未发现合格催化。
