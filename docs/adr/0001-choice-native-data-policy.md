# 本部署使用 Choice 原生接口作为 A 股财务主源

后续决策：[ADR 0002](0002-ifind-complements-choice.md) 已落地六项当前财务、主营分产品及股东明细接入，并于2026-10-15修订为可显式选择 iFinD 优先、Choice 补充和核验；本文件记录初始 Choice 切换决策，其他退休渠道和市场边界保持不变。代码已实现不代表部署已启用或供应商数据已全部验收；运行启用取决于实际配置，验收限制见[接入说明](../ifind-mcp-integration.md)。

根据 PM 的渠道调整与本机 SDK 可行性验证，本部署停用 MX、iFinD、Choice MCP、Fuyao 的实际调用，以 Choice 原生接口作为 A 股财务主源；未停用的公开来源可按一致财期、单位和口径补值，并披露真实来源及缺口，不将同家族数据算作独立佐证。选择这一策略是为了保留可用数据，同时消除旧渠道额度、权限及重复调用路径造成的不确定性；它不承诺 Choice 永不缺失或单源已经完成独立核验。

为保留向上游贡献及以后恢复能力的空间，不全面删除旧适配器；通过统一市场准入配置将本部署的个股功能限定为 A 股，港美股实现保留但不开放新调用，历史记录仍可读取，境外宏观指数引用不受这一产品范围决定误伤。未来同花顺可作为同级供应商接入，但本次仅实现 Choice 并复用现有适配入口，不预建通用插件框架。

用户随后确认本批覆盖七项快照、最多四年年报与现有资金流窗口的替换，以及直接相关的消费断点修复；补值后仍缺失则保留有效内容、明确不完整，不生成依赖缺失依据的评分、估值、目标价或行动结论。真实缺失与实现错误必须区分，后者不能以降级为由通过验收。

业务决策与整案已确认，实施与验收以[Issue #9 正式规格](https://github.com/SkillingX/daily_stock_analysis/issues/9)为准，背景依据见[接入方案](../choice-quantapi-integration.md)。本决策不授权服务器部署；交付先完成 dev 与本机报告验收，后续获授权的施工遵循正式规格。
